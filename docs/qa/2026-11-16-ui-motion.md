# UI motion and rendering pass

Scope: existing global CSS/Tailwind Vite application; no added dependencies, DOM elements, component props, IDs, data attributes, GIS behavior, or store changes. Existing working-tree performance and motion work was retained.

Changes:

- Coalesce map ResizeObserver/window resize notifications into one pending animation frame. Cancel pending work during cleanup; existing event subscriptions remain.
- Replace contextual-tab shadow keyframes with opacity, remove animated progress width while preserving its actual progress value, and use shared deceleration/duration tokens. Micro-interactions use 150–200 ms; reveals/popovers/modals use 300–350 ms. Only opacity and transform are interpolated.
- Refine press feedback to scale 0.98, preserve disabled controls, expose layer actions on keyboard focus, and make focused reveal content visible immediately.
- Harden the existing IntersectionObserver hook: support its declared root option, handle conditionally mounted elements through a stable callback ref, reveal once, honor reduced-motion preferences, and restore temporary will-change hints after completion, cancellation fallback, or unmount. No scroll listener added or removed; table virtualization and menu-dismissal listeners remain intact.
- Reduced-motion CSS removes motion delays and hover transforms and keeps reveal content visible. Focus outlines remain immediate; no shadow/border animation is introduced.
